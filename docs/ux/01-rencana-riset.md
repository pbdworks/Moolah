# Rencana riset dan instrumen

## Tujuan
Menguji kebiasaan mencatat, pembagian uang, toleransi koreksi OCR, dan pemahaman istilah Kantong untuk keputusan IA, form, dan error recovery.

## Rekrutmen & etika
Minimal 5 responden: 2 mahasiswa, 2 pekerja, 1 pengelola keuangan keluarga. Sukarela, anonim, boleh berhenti; jangan meminta saldo, rekening, kredensial, atau struk yang memuat data pribadi. Minta izin rekaman.

## Panduan wawancara 20 menit

| Waktu | Tahap | Pertanyaan/probe |
|---|---|---|
| 0–2 | Pembuka | “Kami menilai produk, bukan Anda. Boleh mencatat?” |
| 2–6 | Kejadian terakhir | “Ceritakan pengeluaran terakhir yang dicatat/diingat.” Probe: kapan, media, apa yang membuat ditunda? |
| 6–9 | Hambatan | “Di bagian mana pencatatan berhenti?” Probe: lupa, waktu, kategori, takut salah, struk. |
| 9–12 | Pembagian uang | “Bagaimana memastikan uang makan/transport/tagihan tidak tercampur?” Probe: amplop, rekening, catatan, aplikasi. |
| 12–15 | Kantong | “Jika ada ruang uang untuk satu tujuan, apa yang harus bisa dilakukan?” Probe: isi, batas, pindah, minus. |
| 15–18 | Scan | “Total terbaca Rp125.000, sebenarnya Rp128.000, tanggal kosong. Apa yang Anda cari/lakukan?” Probe: edit, foto ulang, batal. |
| 18–20 | Prioritas | “Satu perbaikan agar rutin mencatat?” Ulangi temuan untuk konfirmasi. |

Catat kutipan, perilaku aktual, workaround, dan frekuensi; bedakan perilaku dari opini.

## Survei 8 pertanyaan
1. Peran: mahasiswa / pekerja / mengelola keluarga / lain.
2. Frekuensi catat 7 hari: 0 / 1–2 / 3–5 / 6–7 / >7.
3. Media utama: tidak / ingatan / kertas / spreadsheet / budgeting / mobile banking / lain.
4. Alasan menunda: lupa / lama / kategori / takut salah / tidak bawa struk / lain.
5. Yang paling berguna: tujuan Kantong / periode / kategori / tagihan berulang / belum tahu.
6. Field scan wajib editable (pilih): toko / total / tanggal / item / Kantong.
7. Hasil scan “perlu diperiksa”: edit / foto ulang / simpan / batal.
8. Pentingnya offline tanpa akun: skala 1–5 + alasan.

## Analisis
Laporkan n, persentase, denominator, dan missing response. Kodekan pemicu–aksi–hambatan–workaround; kelompokkan pencatatan, Kantong, OCR, privasi, offline. Jangan menggeneralisasi lima orang. Simpan log tanggal, kode responden, pertanyaan terlewat, dan revisi instrumen.
